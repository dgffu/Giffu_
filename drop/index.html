Configurações de Armazenamento
No modo Local, os arquivos originais são gerenciados pelo servidor Python em drop/uploads/. No modo Nuvem, você pode conectar sua própria conta do Supabase ou Cloudflare R2 para hospedagem estática em giffu.com.br/drop.
💡 Configuração do Supabase Storage:
1. Crie seu projeto em supabase.com.
2. Em Storage, clique em New bucket, informe o nome giffu-drop e marque Public bucket.
3. Em Project Settings > API, copie a Project URL (ex: https://xxxx.supabase.co) e a chave anon public.
⚠️ Atenção: Use apenas o domínio base. O sistema limpa automaticamente sufixos como /rest/v1.
🔒 Se receber erro de permissão (RLS), execute no SQL Editor do Supabase:
create policy "Permitir Anon" on storage.objects for all to anon using (bucket_id = 'giffu-drop') with check (bucket_id = 'giffu-drop');
Arquivos com mais de 1 GB são bloqueados automaticamente pelo cliente e pelo servidor.
